# API: профиль пользователя

Экран «Профиль» ([макет](../images/profile.png)) загружается одним запросом `GET /api/v1/users/me`.
Бейдж звания («Исследователь») в API не входит.

## Аутентификация

Запрос идентифицирует пользователя заголовком `Authorization`, схемы описаны в [auth.md](auth.md).

## GET /api/v1/users/me

Возвращает данные текущего пользователя для экрана профиля.

### Запрос

```http
GET /api/v1/users/me
Authorization: vk vk_user_id=1&vk_language=ru&vk_ts=1760700000&sign=...
```

Тела нет.

### Поля

**Пользователь (шапка)**

| Поле         | Тип            | Описание                                     |
| ------------ | -------------- | -------------------------------------------- |
| `id`         | int            | ID пользователя в Swipy                      |
| `first_name` | string \| null | Имя                                          |
| `last_name`  | string \| null | Фамилия                                      |
| `username`   | string         | Ник без `@`; клиент показывает как `@andrey` |
| `points`     | int            | Количество очков пользователя («2 480»)      |

**Статистика**
k
| Поле | Тип | Описание |
| ----------------------- | --- | ---------------------------------------------- |
| `stats.streak_days` | int | Дней занятий подряд |
| `stats.followers_count` | int | Число подписчиков |
| `stats.following_count` | int | Число подписок (на кого подписан пользователь) |

**Курсы** (блок «Мои курсы»). Полный список: курсов у пользователя немного. Порядок — по времени добавления курса.

| Поле                      | Тип    | Описание                                 |
| ------------------------- | ------ | ---------------------------------------- |
| `courses[].id`            | int    | ID курса (`swipy.user_language_pair.id`) |
| `courses[].language.code` | string | Код изучаемого языка (ISO 639-1)         |
| `courses[].language.name` | string | Название языка                           |
| `courses[].language.icon` | string | Иконка или флаг (`swipy.language.icon`)  |
| `courses[].level`         | int    | Уровень в этом курсе                     |

**Дружеские забеги**. Массив, не более 5 элементов, сначала с большим `streak_days`. Если забегов нет, приходит `[]`.

| Поле                         | Тип    | Описание                                                           |
| ---------------------------- | ------ | ------------------------------------------------------------------ |
| `friend_races[].id`          | int    | ID забега                                                          |
| `friend_races[].friend`      | object | Соперник: `id`, `username`                                         |
| `friend_races[].streak_days` | int    | Общий streak: сколько дней подряд оба выполнили ежедневные задания |

**Достижения**. Массив ровно из 4 элементов: сначала полученные (новые первыми), затем заблокированные. Если у пользователя меньше 4 полученных достижений, недостающие места занимают случайные ещё не полученные достижения с `is_locked: true`, клиент показывает их заблокированными.

| Поле                       | Тип    | Описание                                                       |
| -------------------------- | ------ | -------------------------------------------------------------- |
| `achievements[].id`        | int    | ID достижения                                                  |
| `achievements[].icon_url`  | string | Иконка                                                         |
| `achievements[].is_locked` | bool   | `true`: достижение ещё не получено, показывать заблокированным |

Пустые списки приходят как `[]`, а не `null`.

### Ошибки

Формат такой же, как у текущего `ErrorResponse`:

```json
{ "message": "failed verify VK params", "error": "invalid argument" }
```

| Код                         | Когда                                                                                               |
| --------------------------- | --------------------------------------------------------------------------------------------------- |
| `401 Unauthorized`          | Нет заголовка `Authorization`, неизвестная схема или неверная подпись                               |
| `404 Not Found`             | Подпись верна, но пользователь не инициализирован (не вызывался `POST /api/v1/users/initialize`) |
| `500 Internal Server Error` | Внутренняя ошибка                                                                                   |

Подробнее про `401` и `404`: [auth.md](auth.md#ошибки).

## Побочный эффект

Перед ответом сервер выполняет ленивый сброс серий ([db.md](../db.md#сброс-streak)): если серия пользователя или его забега просрочена, она обнуляется в БД. Поэтому `GET` может менять `streak_days`.

## Не входит в этот документ (позже)

Действия с экрана описываются отдельными эндпоинтами:

- смена аватара (иконка карандаша);
- «Добавить друзей», QR и «Поделиться» профилем;
- «Добавить курс» и «Изменить» список курсов;
- полные списки по кнопкам «Все» (забеги, достижения);
- «Смотреть» забег;
- настройки.
